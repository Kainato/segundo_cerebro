## 🛠️ Ferramenta de Automação: N8N

### O Que é N8N?

**N8N** é uma plataforma de **integração e automação visual** que permite:

- 🔗 Conectar diferentes ferramentas (Gmail, Slack, Sheets, etc)
- ⚙️ Criar fluxos de trabalho inteligentes sem código
- 🤖 Implementar lógica de decisão com IA
- 🚀 Escalar processos automaticamente

### Como Funciona?

N8N usa o conceito de **"nós"** (nodes):

```text
Trigger (E-mail chega)
         ↓
    [Nó 1] Recebe e-mail do Gmail
         ↓
    [Nó 2] Envia para IA classificar
         ↓
    [Nó 3] Decisão: Qual categoria?
         ↓
    [Nó 4] Move para pasta apropriada
         ↓
    [Nó 5] Notifica você (opcional)
```

### Vantagem Prática

Você **não precisa programar**! Apenas conecta blocos visuais e define as regras. A IA cuida da lógica complexa.

---

## 🎯 Seu Primeiro Agente: Passo a Passo

1. **Defina o Trigger** (o que dispara o agente)
   - Exemplo: "Novo e-mail chega no Gmail"

2. **Adicione Inteligência** (use IA para pensar)
   - Exemplo: "Classifique este e-mail"

3. **Implemente Lógica** (se/então)
   - Exemplo: "Se é spam, arquive. Se é urgente, notifique"

4. **Execute Ações** (deixe a IA trabalhar)
   - Exemplo: "Mova para pasta, envie notificação"

5. **Monitore e Ajuste** (melhore com o tempo)
   - Exemplo: "Veja relatórios, refine as regras"
