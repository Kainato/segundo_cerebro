# Princípios do Design

Se os elementos são os "blocos de construção", os princípios são as "regras de construção".

Os princípios apresentados na aula incluem:

- **Alinhamento**
- **Contraste**
- **Hierarquia**
- **Movimento**
- **Proximidade**
- **Repetição**
- **Equilíbrio**
- **Unidade**
- **Textura**

A lógica é simples:

> **Elementos → Princípios → Composição → Comunicação**

---

## 📐 Alinhamento

### O Conceito

Elementos não devem parecer posicionados aleatoriamente.

### O que cria

- ✅ Organização visual
- ✅ Consistência
- ✅ Estrutura
- ✅ Sensação de profissionalismo

### No Seu Portfólio

Uma página com títulos, imagens, textos e screenshots desalinhados **imediatamente parece amadora**.

Regra de ouro: **Escolha uma coluna ou grid e respeite-a**.

---

## 🎯 Contraste

### O Conceito

Contraste cria diferenciação e hierarquia.

### Tipos de Contraste

- **Tamanho** (título grande vs. texto pequeno)
- **Cor** (fundo vs. elemento destacado)
- **Peso tipográfico** (bold vs. regular)
- **Forma** (retângulo vs. círculo)
- **Espaço** (elemento isolado vs. agrupado)
- **Posição** (topo vs. rodapé)

### Exemplo

```
TÍTULO GRANDE

Texto secundário menor.
```

Isso imediatamente cria hierarquia sem precisar explicar.

### No Seu Portfólio

Use contraste para **guiar a atenção**:

- O que é importante fica com alto contraste
- O que é secundário fica mais discreto

---

## 📊 Hierarquia

### O Conceito

A apresentação precisa responder em ordem:

1. **"O que eu quero que a pessoa veja primeiro?"**
2. **"O que ela deve perceber em seguida?"**
3. **"O que pode ser lido por último?"**

### Evita

A hierarquia impede que seu projeto vire um "paredão de informação" onde tudo tem a mesma importância.

### Exemplo de Hierarquia em um Projeto

```
Nível 1 → NOME DO PROJETO (maior, em destaque)
Nível 2 → Uma frase explicando o problema
Nível 3 → Imagem/mockup principal
Nível 4 → Processo e explicações
Nível 5 → Detalhes técnicos
```

O visitante naturalmente segue essa ordem.

---

## 🔄 Proximidade

### O Conceito

Elementos relacionados devem ficar próximos.
Elementos não relacionados devem ter separação.

### O Resultado

O usuário entende **grupos visualmente**.

### Exemplo

```
┌─────────────────┐
│ Nome do Projeto │
│ Descrição       │
│ Tecnologias     │
└─────────────────┘

   [espaço grande]

┌─────────────────┐
│ Outro Projeto   │
│ Descrição       │
│ Tecnologias     │
└─────────────────┘
```

Tudo no primeiro bloco é percebido como um grupo.

### No Seu Portfólio

Agrupe:

- Projeto + descrição + imagem = um bloco
- Tecnologias usadas = um grupo
- Deixe espaço entre projetos diferentes

---

## 🔁 Repetição e Consistência

### O Conceito

Se você utiliza determinado padrão visual, ele deve se repetir.

### Exemplos

- ✅ Mesmos estilos de títulos
- ✅ Mesmas margens
- ✅ Mesmos componentes
- ✅ Mesma lógica de espaçamento
- ✅ Mesma linguagem visual

### O Resultado

Isso cria **consistência** — passa uma sensação muito mais profissional.

### Regra para Portfólio

> **Todos os projetos devem ter a mesma estrutura de apresentação.**

Se o primeiro projeto tem layout X, o segundo também deveria ter.

---

## ⚖️ Equilíbrio

### O Conceito

O layout não precisa ser perfeitamente simétrico, mas deve se sentir **equilibrado**.

### Tipos

- **Simétrico** (espelho — mais formal)
- **Assimétrico** (elementos em diferentes posições — mais dinâmico)

Ambos podem ser profissionais. Escolha o que se alinha com sua marca.

---

## 🧩 Unidade

### O Conceito

Todos os elementos trabalham juntos como um **todo coerente**.

Não é uma coleção aleatória de coisas bonitas.

É um **sistema**.

### No Seu Portfólio

Sua página deve:

- ✅ Ter uma direção visual clara
- ✅ Usar linguagem visual consistente
- ✅ Sentir-se como uma experiência única
- ✅ Refletir sua personalidade/marca

---

## 📋 Resumo: Como Aplicar

Para cada página do seu portfólio, pergunte-se:

- [ ] **Alinhamento:** Meus elementos estão alinhados?
- [ ] **Contraste:** Fica claro o que é importante?
- [ ] **Hierarquia:** A pessoa sabe por onde começar a ler?
- [ ] **Proximidade:** Relacionados ficam próximos?
- [ ] **Repetição:** Mantenho consistência entre páginas?
- [ ] **Equilíbrio:** Se sente organizado e equilibrado?
- [ ] **Unidade:** Tudo funciona junto como um sistema?

Se todos os "sim" forem marcados, você tem um portfólio bem estruturado.
