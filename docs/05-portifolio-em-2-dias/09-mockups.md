# Mockups: Contextualizando o Design

Um mockup é a apresentação de um design em um **contexto real**.

A diferença parece simples, mas é poderosa.

---

## Exemplo da Diferença

### ❌ Sem Mockup

```
Logo X
```

Você vê apenas a forma/imagem isolada.

### ✅ Com Mockup

```
Logo X aplicado em:
- Cartão
- Embalagem
- Aplicativo
- Camiseta
- Painel de escritório
```

Você entende como o logo funciona em diferentes contextos.

---

## Aplicação ao Seu Portfólio

Para um aplicativo mobile, por exemplo:

### ❌ Sem Mockup

```
📱 Screenshot do aplicativo
```

É um screenshot isolado. Parece perdido.

### ✅ Com Mockup

```
📱 Smartphone mostrando o aplicativo rodando
   (com bezel realista, tela acesa em contexto)
```

Parece um produto real, não apenas uma imagem.

---

## Tipos de Mockups

### 1. Smartphone Mockup

```
Mostra o app rodando em um telefone real
- Bezel realista
- Tela com conteúdo
- Às vezes com a mão segurando
```

Ideal para: Apps mobile, interfaces de mobile.

### 2. Desktop Mockup

```
Mostra o website/app em um monitor/laptop
- Respeitando proporções reais
- Com o conteúdo rodando
```

Ideal para: Websites, dashboards, aplicações web.

### 3. Tablet Mockup

```
Mostra em um tablet (iPad, etc)
```

Ideal para: Aplicações responsivas.

### 4. Contexto Real

```
Aplicativo rodando em um ambiente real
- Foto da tela do projeto em um smartphone real
- Ou ambiente natural onde seria usado
```

Ideal para: Comunicar uso real, aplicação prática.

---

## Por que Usar Mockups?

### Torna Tangível

```
Sem mockup:  Imagem de interface (abstrata)
Com mockup:  Produto pronto para usar (concreto)
```

### Aumenta Credibilidade

Um mockup bem feito diz:

> "Isso é um produto real, não é apenas um exercício"

### Comunica Melhor

Recrutadores/clientes conseguem visualizar melhor como o produto funciona.

### Profissionalismo

Um portfólio com mockups parece **muito** mais profissional do que sem.

---

## Como Criar Mockups

### Opção 1: Ferramentas Gratuitas

- **Figma** (templates gratuitos de mockup)
- **Mockup Generator** (tools online)
- **Pixelsquid** (modelos 3D)

### Opção 2: Recursos Gratuitos

Websites que fornecem mockups prontos:

- **Pexels.com/mockups**
- **Dribbble** (busque "mockup gratuito")
- **Behance** (busque "smartphone mockup")
- **Placeit.net** (freemium)

### Opção 3: Fazer Screenshots Reais

A abordagem mais honesta:

1. Rode seu aplicativo em um smartphone real
2. Tire uma foto/screenshot
3. Use essa imagem no portfólio

Isso é muito mais valioso que um mockup genérico porque é **real**.

## Estrutura com Mockups

No seu portfólio, você pode estruturar assim:

```
═════════════════════════════════════════════════════════════════

                    NOME DO PROJETO
        Uma frase explicando o problema

                    ┌──────────────┐
                    │ 📱           │
                    │  [App na     │
                    │   tela]      │
                    └──────────────┘
                  (Mockup do app rodando)

            O Problema e A Solução
        Explicação do projeto...

            Screenshots / Iterações
        [Imagens das diferentes telas]

            Tecnologias Utilizadas
        Flutter, Dart, BLoC, etc

            Link para o Projeto
        GitHub | Play Store | Demo

═════════════════════════════════════════════════════════════════
```

## Dicas para Mockups Efetivos

### ✅ Do's

- Use mockups com contexto real
- Mantenha proporções corretas
- Certifique-se de que o conteúdo é legível
- Use cores que destaquem seu app
- Combine com fotos quando possível

### ❌ Don'ts

- Mockups de muito baixa qualidade
- Mockups que não correspondem ao tamanho real
- Demasiadas distorções
- Conteúdo ilegível por causa do mockup
- Usar o mesmo mockup 10 vezes (varie)

---

## Checklist de Mockups

- [ ] Tenho mockups dos principais fluxos do app?
- [ ] Os mockups mostram o app em contexto real?
- [ ] O conteúdo é legível dentro do mockup?
- [ ] Os mockups estão bem alinhados na página?
- [ ] Variei os tipos de mockup (não repeti o mesmo)?
- [ ] Os mockups comunicam o valor do app?

Se a maioria for "sim", seus mockups estão fortes.

## Exemplo Real

Se você tem um **app de lista de tarefas**:

### Página do Portfólio Usando Mockups

```
┌─────────────────────────────────────────────┐
│ APLICATIVO DE TAREFAS                       │
│ Simplificando seu dia a dia                 │
│                                             │
│     ┌──────────┐  ┌──────────┐             │
│     │ 📱       │  │ 📱       │             │
│     │ Tela 1   │  │ Tela 2   │             │
│     └──────────┘  └──────────┘             │
│                                             │
│ Problema: Difícil priorizar tarefas        │
│ Solução: Interface clara com hierarquia     │
│                                             │
│ Tecnologias: Flutter, Supabase, BLoC       │
│                                             │
│ [GitHub] [Play Store] [Demo]               │
└─────────────────────────────────────────────┘
```

Isso comunica muito mais valor do que apenas um link para o GitHub.
