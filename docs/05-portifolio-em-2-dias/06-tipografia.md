# Tipografia: Estruturando Informação

Tipografia não é decoração. É arquitetura da informação.

A escolha de fontes, tamanhos, pesos e espaçamento determina como seu conteúdo é **entendido e lido**.

---

## Categoria de Fontes

Existem diferentes famílias tipográficas, mas para portfólio você provavelmente usará:

### Sans-Serif

```
Helvetica, Roboto, Inter, Poppins, Montserrat
```

**Características:**

- Moderno
- Limpo
- Excelente legibilidade em tela
- Profissional

**Quando usar:** Praticamente sempre em portfólio digital.

### Serif

```
Georgia, Merriweather, Playfair Display
```

**Características:**

- Elegante, clássico
- Às vezes mais formal
- Pior legibilidade em telas pequenas

**Quando usar:** Raramente em portfólio de desenvolvedor. Talvez em um título, mas com cuidado.

### Monospace

```
Courier, Inconsolata, JetBrains Mono
```

**Características:**

- Para código
- Técnico

**Quando usar:** Quando você precisa mostrar código ou em contextos técnicos.

## Construindo Hierarquia com Tipografia

Você deve criar **níveis de informação claros**:

### Nível 1: Título Principal

```
Tamanho: 48px ou maior
Peso: Bold (700) ou Extra-Bold (800)
Cor: Cor primária
Espaçamento: Espaço gerado ao redor
```

**Exemplo:**

```
NOME DO PROJETO
```

### Nível 2: Subtítulo

```
Tamanho: 24px
Peso: Regular (400) ou Medium (500)
Cor: Cor principal (menos saturada) ou secundária
Espaçamento: Espaço moderado
```

**Exemplo:**

```
Uma descrição clara do projeto
```

### Nível 3: Corpo de Texto

```
Tamanho: 16px (desktop) ou 14px (mobile)
Peso: Regular (400)
Cor: Cor de texto principal (geralmente preto ou cinza escuro)
Espaçamento: Line-height de 1.5 a 1.8 para conforto
```

**Exemplo:**

```
Este é o texto principal que a pessoa vai ler.
Ele deve ser confortável de ler e ter contraste suficiente.
```

### Nível 4: Informação Auxiliar

```
Tamanho: 12px
Peso: Regular (400)
Cor: Cinza, cor muted, ou baixo contraste
Espaçamento: Normal
```

**Exemplo:**

```
Tecnologias: Flutter, Dart, BLoC
Desenvolvido em 2026
```

## Combinação de Fontes

### Regra Simples

Para portfólio, use **no máximo 2 fontes**:

1. **Uma sans-serif** para corpo e interface
2. **Opcionalmente, outra sans-serif ou serif** para títulos

### ✅ Combinações que Funcionam

```
Inter (corpo) + Poppins (títulos)
Roboto (corpo) + Montserrat (títulos)
Raleway (corpo) + Playfair Display (títulos)
```

### ❌ Combinações a Evitar

```
5 fontes diferentes ← confuso demais
Serif + Serif incompatíveis ← chato
Fontes muito pesadas + muito finas ← desconfortável
```

## Espaçamento Tipográfico

### Line-Height (Altura da Linha)

```
Título: 1.0 a 1.2
Subtítulo: 1.2 a 1.4
Corpo: 1.5 a 1.8
```

Linha maior = mais confortável de ler.

### Letter-Spacing (Espaço entre Letras)

```
Normal: 0
Títulos grandes: +0.05em a +0.1em (mais arejado)
Corpo: 0 (normal)
```

### Paragraph-Spacing (Entre Parágrafos)

```
Entre parágrafos: 1.5x do tamanho da font
Entre seções: 3x do tamanho da font
```

---

## Alinhamento Tipográfico

### Left-Align (Alinhado à Esquerda)

```
Mais legível
Padrão em portfólio
Recomendado
```

### Center-Align (Centralizado)

```
Apenas títulos/destaques
Não use para corpo
Reduz legibilidade em grandes volumes
```

### Right-Align (Alinhado à Direita)

```
Raramente use
Difícil de ler
```

---

## Contraste e Legibilidade

### Ratio de Contraste

- **Normal:** 4.5:1 (recomendado para acessibilidade)
- **Bom:** 7:1 (excelente)
- **Nunca:** Menos de 3:1 (muito difícil ler)

**Dica:** Use ferramentas como WebAIM Contrast Checker.

### Tamanho Mínimo

- **Corpo:** 16px (não mais pequeno)
- **Auxiliar:** 12px (exceção)
- **Nunca:** Menos de 10px

## Checklist de Tipografia

- [ ] Minhas 2 fontes principais funcionam bem juntas?
- [ ] Cada nível de hierarquia tem tamanho diferente?
- [ ] O corpo está em 16px ou maior?
- [ ] O contraste é suficiente (4.5:1 ou melhor)?
- [ ] Line-height do corpo está entre 1.5 e 1.8?
- [ ] Uso alinhamento left para corpo (não centro)?
- [ ] Os títulos têm destaque visual claro?
- [ ] Informações auxiliares são discretas?

Se todos os checkboxes estiverem marcados, sua tipografia está strong.
