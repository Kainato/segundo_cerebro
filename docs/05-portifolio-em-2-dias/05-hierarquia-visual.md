# Hierarquia Visual na Prática

A hierarquia visual é tão importante que merece sua própria seção. Este é um dos conceitos mais críticos para um portfólio que funciona.

## O Problema

Quando tudo em uma página tem a mesma importância visual, o visitante fica **perdido**.

Ele não sabe:

- Por onde começar
- O que é mais importante
- Para onde seu olho deveria ir primeiro

---

## A Solução: Hierarquia Visual

A hierarquia responde três perguntas em ordem:

### 1️⃣ Primeira Coisa

> **"O que eu quero que a pessoa veja PRIMEIRO?"**

Essa é a informação mais importante. Ela deve ser:

- Maior
- Com mais contraste
- No topo ou em destaque
- A primeira coisa que o olho encontra

### 2️⃣ Segunda Coisa

> **"O que ela deve perceber EM SEGUIDA?"**

Informação importante, mas secundária à primeira. Pode ser:

- Um pouco menor
- Com menos contraste
- Abaixo da primeira
- Ainda visível, mas não dominante

### 3️⃣ Terceira Coisa

> **"O que pode ser lido POR ÚLTIMO?"**

Detalhes, informação auxiliar, "o que está ali se precisar". Pode ser:

- Pequeno
- Com pouco contraste
- Discreto
- Muitas vezes ignorado (e tudo bem)

---

## Exemplo Prático: Página de Um Projeto

Vamos estruturar a hierarquia de uma página de projeto:

### Nível 1 (Mais importante)

```
NOME DO PROJETO
```

Deve ser:

- **Muito grande** (48px ou maior)
- **Bold ou extra-bold**
- **Cor primária ou destaque**
- **No topo**

### Nível 2 (Importante)

```
Uma frase explicando o problema que foi resolvido
```

Deve ser:

- **Grande** (24px)
- **Regular (não bold)**
- **Cor principal, mas menos ênfase**
- **Logo abaixo do título**

### Nível 3 (Muito importante — visual)

```
[IMAGEM/MOCKUP PRINCIPAL]
```

Deve ser:

- **A imagem mais chamativa da página**
- **Bem proporcionada**
- **Ocupando espaço significativo**

### Nível 4 (Importante — context)

```
O PROCESSO

Aqui você explica como chegou à solução,
decisões de design, alternativas consideradas, etc.
```

Deve ser:

- **Corpo de texto padrão**
- **Bem legível**
- **Com bom contraste**

### Nível 5 (Secundário)

```
Tecnologias:
Flutter, Dart, BLoC, REST API, Supabase
```

Pode ser:

- **Menor** (12px)
- **Menos contraste**
- **Discreto**

### Nível 6 (Opcional)

```
Links para GitHub, demo, vídeo
```

Pode estar:

- **Bem menor**
- **No rodapé**
- **Muitas vezes ignorado**

## Ferramentas para Criar Hierarquia

Você pode usar **qualquer uma (ou combinação) dessas**:

### 1. Tamanho

```
Título grande
Subtítulo médio
Corpo pequeno
```

### 2. Peso Tipográfico

```
TÍTULO (bold)
Subtítulo (regular)
Texto auxiliar (regular)
```

### 3. Cor

```
Título → Cor principal (alta saturação)
Subtítulo → Cor secundária (menos saturação)
Auxiliar → Cor muted/cinza (baixo contraste)
```

### 4. Contraste

```
Alto contraste → Importante
Médio contraste → Secundário
Baixo contraste → Auxiliar
```

### 5. Espaçamento

```
Elemento importante → Mais espaço ao redor
Elemento auxiliar → Menos espaço
```

### 6. Posição

```
Topo/centro → Mais importante
Rodapé/cantos → Menos importante
```

---

## Aplicação ao Seu Portfólio

Para cada página, você deve:

1. **Identificar** qual é a informação mais importante
2. **Destacar** essa informação (tamanho, cor, contraste, espaço)
3. **Organizar** as demais em ordem de importância
4. **Testar** com amigos: "Por onde você começaria a ler?"

Se todos disserem a mesma coisa, sua hierarquia funcionou.

---

## Checklist

- [ ] Meu título é notavelmente maior que outros textos?
- [ ] Minha imagem principal está bem posicionada e dimensionada?
- [ ] Fica claro o que é mais importante apenas olhando?
- [ ] A leitura flui naturalmente de um ponto a outro?
- [ ] Informações importantes têm destaque visual?
- [ ] Informações auxiliares são discretas mas acessíveis?

Se todos os checkboxes estiverem marcados, você tem uma hierarquia visual forte.
