# Composição Visual e Gestalt

Composição visual é a **organização intencional de elementos para comunicação eficaz**.

Não é simplesmente "colocar coisas na tela". É decidir **onde, como, por quê e em qual ordem** cada elemento aparece.

---

## O que Entra em Jogo

Uma boa composição trabalha com:

- Grid e estrutura
- Contraste
- Alinhamento
- Equilíbrio
- Figura/fundo
- Espaço negativo
- Hierarquia
- Gestalt

---

## Grid: A Base Invisível

Grid é uma **estrutura invisível** utilizada para organizar elementos.

### Como Funciona

Um grid pode trabalhar com:

- **Colunas** (12 colunas é padrão em web)
- **Margens** (espaço dos lados)
- **Módulos** (unidades de tamanho)
- **Espaçamento** (consistência entre elementos)

### O Ponto Importante

> O grid **não deixa o layout "preso"**. É justamente o contrário.
>
> O grid fornece uma **estrutura para você quebrar regras de maneira consciente**.

### Aplicação Prática

Antes de montar seu portfólio, defina:

- [ ] Largura máxima (ex: 1200px)
- [ ] Número de colunas (ex: 12)
- [ ] Margens (ex: 1rem dos lados)
- [ ] Espaçamento entre elementos (ex: 2rem)
- [ ] Posição de títulos (sempre no topo esquerdo)
- [ ] Posição de imagens (como elas fluem)
- [ ] Largura dos textos (máximo 80 caracteres por linha)

Depois que isso está definido, você tem **liberdade criativa dentro da estrutura**.

## Princípios de Gestalt

A aula apresenta princípios da **Gestalt**, que é a teoria de como o cérebro interpreta informação visual.

### Ideia Central

> O cérebro não interpreta cada elemento isoladamente.
>
> **Ele tenta perceber padrões e relações.**

### Princípios Principais

#### 1. Proximidade

Elementos próximos são percebidos como um grupo.

```
🔷 🔷 🔷     [espaço grande]     🔶 🔶 🔶
```

Você vê dois grupos, não 6 elementos aleatórios.

#### 2. Semelhança

Elementos com mesmas características são percebidos como grupo.

```
🔷 🔷 🔷    [diferentes]    🔶 🔶 🔶
```

Mesma forma = mesmo grupo.
Forma diferente = grupo diferente.

#### 3. Fechamento

O cérebro "completa" formas incompletas.

```
◇ ◇ ◇       ← cérebro vê um círculo
◇     ◇       mesmo incompleto
◇ ◇ ◇
```

#### 4. Figura/Fundo

O cérebro distingue entre elemento principal (figura) e contexto (fundo).

```
Texto preto (figura) em fundo branco (fundo)
```

Contraste = figura fica clara.

#### 5. Simetria e Equilíbrio

Layouts simétricos (ou equilibrados) parecem mais organizados.

```
Simétrico: [logo] [menu menu menu] [logo]
Assimétrico: [logo] [menu menu menu]
```

Ambos podem funcionar. Escolha um.

#### 6. Pregnância/Simplicidade

Formas simples são mais fáceis de lembrar e processar.

```
⭕ (fácil de lembrar)
vs.
[forma complexa e irregular]
```

### Aplicação ao Seu Portfólio

Pense menos em:

> "Onde vou colocar essa imagem?"

E mais em:

> "Como quero que o cérebro do visitante agrupe e interprete essas informações?"

## Espaço Negativo como Ferramenta

Espaço negativo (aquele "vazio") é **ativo e intencional**.

### Funções

- Destaca elementos importantes
- Reduz sensação de sobrecarga
- Melhora leitura
- Cria foco

### Exemplo

```
SOBRE MIM

Desenvolvedor Flutter com 5 anos de experiência.


┌─────────────────────────────────┐
│  Projeto 1                      │
│                                 │
│  Descrição do projeto           │
└─────────────────────────────────┘


┌─────────────────────────────────┐
│  Projeto 2                      │
│                                 │
│  Descrição do projeto           │
└─────────────────────────────────┘
```

Esse espaço entre projetos é **intencional**. Ajuda a separar grupos.

## Composição na Prática

### Passo 1: Defina o Grid

"Vou usar um layout de 12 colunas com margens de 1rem."

### Passo 2: Organize em Grupos (Gestalt)

"Projeto + Imagem + Descrição = um grupo.
Cada projeto é separado."

### Passo 3: Aplique Hierarquia

"Título do projeto é o maior.
Descrição é menor.
Tecnologias são ainda menores."

### Passo 4: Use Espaço Negativo

"Entre grupos coloco 3rem de espaço.
Dentro do grupo, 1rem."

### Passo 5: Teste

"Mostra para alguém e pergunta: você entende a estrutura?"

## Checklist de Composição

- [ ] Tenho um grid/estrutura definida?
- [ ] Elementos relacionados estão próximos (proximidade)?
- [ ] Elementos com mesmas características parecem um grupo (semelhança)?
- [ ] O layout é simples e fácil de entender?
- [ ] Tenho figura e fundo claros (contraste)?
- [ ] O espaço negativo está sendo usado intencionalmente?
- [ ] Não parece uma bagunça visual?
- [ ] A hierarquia fica clara apenas olhando?

Se a maioria das respostas for "sim", sua composição é forte.
