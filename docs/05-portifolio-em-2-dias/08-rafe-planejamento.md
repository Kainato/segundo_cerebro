# Rascunho (Rafe) e Planejamento

Uma das fases mais importantes do processo é geralmente **ignorada por desenvolvedores**: o planejamento.

A aula apresenta o conceito de **rafe** (rascunho rápido), que é onde a mágica começa.

---

## O que é Rafe?

Rafe é um **rascunho rápido** onde você:

- Experimenta ideias
- Testa layouts
- Posiciona elementos
- Explora alternativas
- Identifica problemas
- Refina o conceito

### O Ponto Chave

> **Não tente fazer a versão final imediatamente.**

A tentação de abrir o Figma/code e começar a "fazer" é forte. Mas antes disso:

```
1. Pense
   ↓
2. Organize (no papel/quadro branco)
   ↓
3. Rascunhe
   ↓
4. Refine
   ↓
5. Produza (aí sim, open Figma/code)
```

---

## Por que Rafe Importa?

### ❌ Sem Rafe

```
Abre Figma
Fica preso em detalhes
Muda de ideia 10 vezes
Perde tempo
Resultado final é confuso
```

### ✅ Com Rafe

```
Rascunha rapidamente (10 min)
Testa múltiplas ideias (20 min)
Escolhe a melhor (5 min)
Refina no Figma (30 min)
Resultado é claro e coerente
```

---

## Processo de Rafe

### Fase 1: Brainstorm

**Pergunta:** "O que eu quero comunicar?"

Não se preocupe com estética. Apenas anote:

```
- Problema do projeto
- Solução proposta
- Elementos visuais (imagens, ícones, etc)
- Textos principais
- Chamadas à ação
```

### Fase 2: Exploração de Layouts

Rascunhe **múltiplas possibilidades**:

```
Layout 1:
┌──────────────────┐
│ Título           │
├──────────────────┤
│ Imagem           │
├──────────────────┤
│ Texto            │
└──────────────────┘

Layout 2:
┌──────────┬───────┐
│ Título   │       │
├──────────┤ Imag  │
│ Texto    │ em    │
└──────────┴───────┘

Layout 3:
┌─────────────────────┐
│ Título | Imagem     │
├─────────────────────┤
│ Texto descritivo    │
└─────────────────────┘
```

Teste pelo menos 3 versões.

### Fase 3: Decisão

Escolha o layout que:

- ✅ Comunica melhor
- ✅ É mais fácil de navegar
- ✅ Parece profissional
- ✅ Se alinhas com sua marca

### Fase 4: Refinamento no Rafe

Ainda no papel, adicione:

- Tamanhos aproximados
- Espaçamento
- Posições de texto
- Onde imagens vão
- Hierarquia

### Fase 5: Validação

Mostre seus rascunhos para alguém:

"Qual layout você acha melhor?"

Se 2-3 pessoas escolherem o mesmo, você tem um vencedor.

---

## Aplicação para Portfólio de Software

Esse processo vale perfeitamente para projetos de software:

```
Problema
   ↓
Ideias (o que comunicar)
   ↓
Rascunhos (como apresentar)
   ↓
Estrutura (grid, hierarquia)
   ↓
Design (cores, tipografia)
   ↓
Implementação (código/Figma)
   ↓
Resultado (página final)
```

### Exemplo Prático

**Você tem um app Flutter de tarefas e quer criar uma página no portfólio.**

#### Rascunho 1

```
┌─────────────────────┐
│ Aplicativo Tarefas  │
├─────────────────────┤
│ [Imagem grande]     │
├─────────────────────┤
│ Problema e solução  │
├─────────────────────┤
│ Tecnologias        │
└─────────────────────┘
```

#### Rascunho 2

```
┌─────────────────┬──────────┐
│ Aplicativo      │ [Imagem] │
│ Tarefas         │          │
│                 │          │
│ Problema: X     │          │
│ Solução: Y      │          │
└─────────────────┴──────────┘
[Tecnologias]
```

#### Rascunho 3

```
┌─────────────────────┐
│ Aplicativo Tarefas  │
│ [Imagem hero]       │
├─────────────────────┤
│ Problema   │ Solução│
├─────────────────────┤
│ Processo   │ Screenshot
└─────────────────────┘
```

Você testa os 3 com amigos. Digamos que a maioria prefere o Rascunho 2.

Você refina o Rascunho 2 (adiciona tamanhos, espaçamento) e depois leva pro Figma/código.

---

## Ferramentas para Rafe

- **Papel e lápis** ← melhor opção, sem distrações
- **Quadro branco** ← se estiver com alguém
- **iPad + Procreate** ← se preferir digital
- **Figma com wireframes** ← mais formalizado, menos exploratório

---

## Tempo de Rafe

- Brainstorm: 5-10 min
- Exploração: 15-20 min
- Decisão: 5 min
- Refinamento: 10-15 min
- **Total: ~45 min**

Isso economiza **horas** de trabalho no design/código depois.

---

## Checklist de Rafe

Antes de abrir Figma/code:

- [ ] Entendo o problema que estou comunicando?
- [ ] Defini os elementos principais?
- [ ] Testei pelo menos 2-3 layouts?
- [ ] Escolhi um layout que funciona?
- [ ] Defini hierarquia visual (tamanhos relativos)?
- [ ] Validei com alguém?

Se todos estiverem marcados, você está pronto para a próxima fase.

---

## A Mentalidade do Rafe

O rafe é onde você **falha rapidamente** e **barato**.

Muito melhor perder 10 minutos mudando um rascunho do que 2 horas refazendo tudo no Figma.

Então **seja rápido, seja exploratório, e não se apegue a nenhuma ideia ainda**.

A melhor ideia vem da exploração, não do perfeccionismo.
