## 💼 Projeto Real: Onboarding de RH

Vamos trabalhar com um exemplo prático e aplicável: estruturar um **programa de integração para novos funcionários**.

### 📍 Contexto

- **Setor**: Recursos Humanos de uma empresa de Marketing
- **Objetivo**: Desenvolver um treinamento de integração completo
- **Público**: Novos funcionários
- **Resultado**: Sistema automatizado e escalável

### 🔄 Metodologia de Execução

A técnica consiste em **quebrar grandes desafios em etapas menores e simples**:

- Facilita a gestão psicológica do projeto
- Mantém a motivação ao concluir cada fase
- Torna o desenvolvimento mais organizado e previsível

### 📋 Etapas do Projeto

| Etapa | Descrição | Ferramentas |
| ----- | --------- | ----------- |
| **1. Conteúdo** | Criação do treinamento inicial estruturado | ChatGPT, Claude |
| **2. Suporte** | Mecanismo para sanar dúvidas dos integrantes | FAQ gerado por IA |
| **3. Design** | Transformação em apresentação visual profissional | Gamma, Canva |
| **4. Validação** | Testes com novo grupo de funcionários | Feedback & Iteração |

## 🛠️ Aplicação do Método com Arquivos

### Documentos como Base de Conhecimento

Uma das técnicas mais poderosas é usar **documentos anexos** (como PDFs, Word, etc.) para:

- 📄 Fornecer a base de conhecimento necessária
- 🎯 Gerar apresentações personalizadas
- 📝 Criar roteiros específicos para sua empresa
- ⚡ Automatizar processos repetitivos

Isso permite que a IA trabalhe com seus próprios dados e contexto, gerando resultados muito mais alinhados com sua realidade.

---

## ⭐ Ferramenta de Destaque: Gamma

### O que é Gamma?

**Gamma** é uma ferramenta revolucionária que transforma:

- 📝 Roteiros estruturados → Apresentações visuais completas
- 💡 Ideias e anotações → Decks profissionais
- 📊 Dados brutos → Apresentações elegantes e impactantes

### Como Usar Gamma no Seu Projeto

```text
1. Estruture seu conteúdo com IA (ChatGPT/Claude)
2. Exporte ou copie o resultado
3. Cole em Gamma
4. IA gera design automaticamente
5. Personalize conforme necessário
6. Exporte para apresentar
```

**Resultado**: Uma apresentação profissional criada em minutos, não horas!

## 📚 Exemplos de Aplicação

### 📌 Exemplo 1: Plano de Onboarding Estruturado

**Prompt para ChatGPT:**

```text
Preciso estruturar um plano de onboarding para novos funcionários na área de atendimento ao cliente.

Crie um cronograma com:
- Principais treinamentos dos primeiros 30 dias
- Atividades de integração
- Responsáveis por cada fase
- KPIs de sucesso

Formate para ser facilmente visualizável em apresentação.
```

### 📌 Exemplo 2: Design e Boas Práticas de UX

**Fluxo de trabalho:**

1. **IA gera conteúdo**: Boas práticas para navegação intuitiva
2. **IA sugere estrutura**: Hierarquia visual e elementos-chave
3. **Gamma desenha**: Cria slides profissionais automaticamente
4. **Você refina**: Ajusta cores, logos e personalizações
